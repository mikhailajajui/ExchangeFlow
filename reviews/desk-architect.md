## Headline findings

- **ADR-021 conflict (High; needs a decision).** Tellers use the desk live, which is production in ADR-021's terms. The shipped rules are TRIAL (`nonProduction: true`, with placeholder values), and they produce "Within branch limits … You may complete the exchange" plus the reason text "Approved automatically under current policy." Nothing enforces ADR-021's guard. Recommended fix: a trial floor that follows the ADR-022 pattern (DESK-ARCH-03). The alternative is a dated, named deviation signed by the product owner.
- **A printed record can be checked but not replayed today (High).** P7 and P8 show that the context and the decision are reproducible, but only while the exact rules file is still on disk. Head office edits the file in place, the server hot-reloads it, and nothing archives earlier versions. `version` is not tied to content (P6). Changing the compiler also changes `policyHash` for an unchanged file. Fix: an append-only archive keyed by `policyHash`, plus a server-side ledger that holds IDs and hashes only (DESK-ARCH-05, -06).
- **The dependency direction is acceptable, but placement is not.** The desk imports `policy-core`, `workflow-core` and `adapter-rates`. All of these point inward, so the rule holds and skipping `app-services` is defensible for a stateless tool. However, `compilePolicy` and `RulesFileSchema` are business rules that sit inside an app. They should move now into a pure package that the main app will import later (DESK-ARCH-01). The browser bundle is free of Node code (DESK-ARCH-02).
- **Three rules-file fields do less than their names say.** `headOfficeReviewAbove` has no visible effect on the record (P1 and P2 print the same thing). The `absoluteBranchMax` guardrail can never fire (P4), and head office owns it, not compliance as ADR-025 requires. HO-PAYMENT-METHOD and `prohibitedRequestTypes: ['WIRE']` are unreachable (P3, P11). None of this is unsafe, but it misleads whoever edits the file (DESK-ARCH-08 to -11).
- **The desk can converge without rework if three things are done now:** the shared compiler package, the policy archive, and a vocabulary mapping. Records should **not** be migrated into `exchange_request` rows. An ADR is warranted (DESK-ARCH-14; draft below).
